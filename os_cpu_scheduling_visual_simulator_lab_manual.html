Experiment Aim, Objectives & Core Formulas

AIM

To write C programs and visually simulate CPU scheduling algorithms — First-Come First-Served (FCFS), Shortest Job First (SJF / SRTF), Round Robin (RR), and Multi-Level Feedback Queue (MLFQ) — to compute Completion Time, Turnaround Time, Waiting Time, Response Time, and construct Gantt charts.

Key Scheduling Formulas

Completion Time (CT) Time when process finishes
Turnaround Time (TAT) TAT = CT − AT
Waiting Time (WT) WT = TAT − BT
Response Time (RT) RT = First Start − AT

Algorithm Characteristics

  • FCFS (Non-Preemptive): Dispatches processes strictly in order of arrival time. Simple to implement with a FIFO queue, but suffers from the Convoy Effect when a long CPU-bound job blocks short jobs behind it.
  • SJF / SRTF: Selects the ready process with the smallest burst time (non-preemptive SJF) or smallest remaining burst time (preemptive SRTF). Provably minimizes average waiting time, though long jobs may face starvation.
  • Round Robin (Preemptive): Assigns a fixed Time Quantum (q) to each ready process in circular FIFO order. Guarantees fair response time for time-sharing systems; performance depends strongly on choosing q properly.
  • Multi-Level Feedback Queue (MLFQ): Uses multiple priority queues (here Q0: RR q=2, Q1: RR q=4, Q2: FCFS). New jobs start in Q0; if a job uses its full quantum without finishing, it is demoted to a lower queue, naturally favoring short interactive tasks without requiring prior knowledge of burst times.
